# The Fragile Peace

A **Legend of the Five Rings (5th Edition)** campaign site — the archive of
**Doji Setsuna**, Crane Clan, Doji Bureaucrat, Emerald Magistrate and Personal Advisor
to the Imperial Envoy Miya Misato, in the brokering of a peace between the Lion and
the Unicorn.

This site is kept from the **player's** side of the table. There is no Game Master
section in it.

Structure, theme and engines are modelled on
[`portents-and-fortunes`](../2026%20Portents%20%26%20Fortunes/portents-and-fortunes) —
parchment ground, Imperial crimson (`#B62432`), Cormorant display serif with Barlow
Condensed furniture, and clan *mon*.

## Structure

Generated by `scripts/build_site.py` from the gitignored `ingest/` export plus the
hand-authored session files in `sources/chronicle/`. No bundler; plain static HTML
for GitHub Pages.

| Path | What it is |
|------|------------|
| `index.html` | Home — masthead + section grid |
| `character/` | Doji Setsuna's dossier (`setsuna.html`) and the character index |
| `party/` | The company — at the table, the ancestral company of the Snow Plain, and those off stage |
| `play/` | **Interactive L5R5e character sheets** — `setsuna.html` and `morozane.html`, sharing `sheet.js` / `sheet.css` / `l5rdata.js` |
| `chronicle/` | 39 session pages (Chronicle · Timeline · Entities tabs), prev/next, + index |
| `dramatis-personae/` | 178 NPCs, knowledge-gated — see *What Setsuna knows* below |
| `map/` | **Interactive Atlas** — the Rokugan overview; click a clan's territory to descend into its own regional map (pan/zoom). `map.js` holds the territory polygons + region config |
| `atlas/` | Gazetteer — 145 places, map-pin targets live here as `#anchors` |
| `lore/` | The Emerald Empire — 56 factions, 38 relics, Bushidō and the Celestial Order |
| `notes/` | **Player Notes** — the player's working papers, tagged claims, open threads |
| `assets/` | Map, portrait, clan `mon/`, ring icons, and dice-face SVGs (`dice/`) |

## What came from where

- **Setsuna's dossier** (`character/setsuna.html`) is the dossier from
  `~/Working/dossiers/characters/doji-setsuna/dossier.html`, **prose unedited**. Only the
  page chrome changed: title, favicon, the site nav bar and footer, the Barlow Condensed
  webfont for that nav, and the portrait `src` repointed at `../assets/setsuna.webp`.
- **The playable sheet** (`play/setsuna.html`) is the Portents & Fortunes deployment of
  the sheet generated by `~/Working/doji-setsuna/build/build_sheet.py`, with the brand,
  page title and the link to Norikage's sheet removed. ⚠ **That build script does not
  know about this repo** — it writes only its own `index.html` and the Portents copy.
  Re-running it will not update the copy here; add a third target, or re-port by hand.
- **Theme and engines** (`rokugan.css`, `map/`, `dramatis-personae/dramatis.*`,
  `play/sheet.*`, `play/l5rdata.js`) are copied verbatim from Portents & Fortunes, except:
  - `rokugan.css` — the "Behind the Veil" nav styling became `.topnav a.notes`, and
    `.gm-mast` became `.notes-mast`.
  - `map/map.js` — the Dragon-lands gazetteer pins were removed (that gazetteer content
    is not part of this campaign).
  - `dramatis-personae/` no longer runs the Portents JS roster app at all. The GM
    toggle is gone; the section is generated static pages with the mask model below.
  - `play/sheet.js` gained a guarded companion card (Morozane's lion) and no longer
    aborts the render when a sheet carries no bushidō tenets, ninjō or giri.

## Regenerating

The site is generated from the gitignored `ingest/` export plus the hand-authored
session files in `sources/chronicle/`:

```bash
python3 scripts/build_site.py
```

That wipes and rebuilds `chronicle/`, `party/`, `dramatis-personae/`, `atlas/` and
`lore/` only. Everything else is left alone.

Morozane's playable sheet is built separately, from his pinned Foundry export plus
the L5R5e corpus:

```bash
python3 scripts/build_morozane_sheet.py
```

### What Setsuna knows

`scripts/build_site.py` decides nothing about this. Each session file under
`sources/chronicle/` carries the adjudication:

- the company tells each other what it learns, so **known is the default** for
  everyone a session names;
- `unknown:` lists the exceptions — what a companion deliberately kept back
  (session 4's Yushi Sama, session 8's Doji-crested cloth);
- `mode: flashback` marks sessions 10–16, which Setsuna lived as the memories of
  her ancestor **Matsu Morozane**; those render as *remembered, not lived*;
- a session with no file at all is **pending** — never assumed either way.

Masked bars on a Dramatis Personae page are empty elements. There is no content
behind them, because we do not have it.

## Local preview

```bash
python3 -m http.server 8734 --directory .
```

Then open <http://localhost:8734/>. (A `fragilepeace` entry is registered in the Claude
Code launch config on port 8734.)
